# Mafia Host Tool

Клиентский Fabric-мод для ведущего игры в мафию. Целевая версия: **Minecraft Java 1.21.11**. Автор: **mlpgod**.

## Возможности

- Открытие окна клавишей **M**. Клавишу можно переназначить в настройках управления Minecraft.
- Настройка числа участников от 1 до 50.
- Ввод ников через запятую, точку с запятой или `|` до раздачи. Если ников меньше, оставшиеся места получат имена `Игрок N`.
- Добавление собственных ролей, их сохранение, включение и выключение, настройка количества экземпляров каждой роли.
- Автоматическое заполнение оставшихся мест ролью **Мирный житель**.
- Редактирование имён прямо в списке после раздачи.
- Копирование готового списка «ник — роль» в буфер обмена.
- Мод работает только на клиенте, не отправляет роли на сервер и не приостанавливает игру.

Названия и настройки ролей хранятся в `.minecraft/config/mafiatool-roles.txt`.

## Установка

1. Установите Fabric Loader для Minecraft 1.21.11.
2. Установите Fabric API той же версии игры.
3. Скачайте файл `mafia-host-tool-*.jar` из раздела **Artifacts** последней успешной сборки GitHub Actions.
4. Поместите JAR в папку `.minecraft/mods` и запустите профиль Fabric.

## Сборка локально

Нужен **JDK 21**. В корне проекта выполните:

- Windows: `gradlew.bat build`
- Linux/macOS: `./gradlew build`

Готовый мод появится в `build/libs/`. Исходный JAR с суффиксом `-sources` и промежуточный `-dev` для установки не нужны.

## Сборка на GitHub

Workflow `.github/workflows/build.yml` запускает сборку при push, pull request или вручную через вкладку **Actions**. JAR можно скачать из артефактов успешного запуска. Workflow использует официальные GitHub Actions для checkout, установки Java и загрузки артефакта.
