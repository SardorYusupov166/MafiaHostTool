# MafiaHostTool

Клиентский Fabric-мод для ведущего настольной «Мафии». Первый релиз включает подготовку и проведение нескольких партий, журнал событий, голосования и архив. Мод не отправляет роли на игровой сервер и не зависит от ChatSorter или MigosRules.

**Minecraft:** Java Edition 1.21.11
**Fabric Loader:** 0.19.5
**Fabric API:** 0.141.6+1.21.11
**Java:** 21

## Возможности

- Нажмите **M**, чтобы открыть список активных партий и архив.
- Создавайте несколько независимых партий, задавайте название, добавляйте игроков по одному или списком.
- Создавайте и сохраняйте шаблоны ролей; настраивайте команду, описание, фазу действия, количество и доступность.
- Для каждой партии хранится свой снимок выбранных ролей. Распределение запускается только после подтверждения и не меняется при повторном открытии.
- Открывайте партию в компактном окне справа: список игроков и журнал переключаются вкладками, а игровой чат остаётся виден рядом.
- Нажмите **T** или «Написать в чат», чтобы открыть игровой чат; после отправки сообщения или закрытия чата окно партии откроется снова.
- В списке участников смотрите роли и команды, отмечайте смерть или исключение, возвращайте игрока, меняйте ник и роль, открывайте лог выбранного игрока.
- Переключайте день и ночь вручную, записывайте игровые действия и их результаты, исправляйте ошибочные записи с сохранением исходного события. Формы записи и полного журнала также открываются компактными окнами.
- Открывайте полный журнал партии или отдельную историю игрока; фильтруйте записи по фазе, участнику и типу события.
- Проводите дневное голосование, смотрите подсчёт и ничьи; исключение по итогам требует подтверждения.
- Завершайте и восстанавливайте партии, просматривайте архив, импортируйте и экспортируйте партию в JSON.

## Данные и сохранение

Данные находятся в клиентской папке Minecraft:

- `config/mafiatool/games/` — отдельный JSON-файл на партию и резервная копия;
- `config/mafiatool/roles.json` — библиотека ролей и резервная копия.

Изменения сохраняются автоматически. Запись партии выполняется через временный файл с атомарной заменой, когда это поддерживается файловой системой. При повреждении отдельной партии мод пробует восстановить её из `.bak` и продолжает загружать остальные. Старый файл партий из предыдущей версии переносится при первой загрузке.

## Установка

Установите Fabric Loader и Fabric API для Minecraft 1.21.11. Возьмите JAR из `build/libs/` после сборки либо из артефактов успешного GitHub Actions и поместите его в `.minecraft/mods`.

## Сборка из исходников

Установите JDK 21, затем в корне проекта выполните:

```powershell
./gradlew.bat build
```

В Linux/macOS:

```bash
./gradlew build
```

Собранный мод появится в `build/libs/`. GitHub Actions запускает сборку при push и pull request; JAR можно скачать в разделе **Actions → Artifacts**.
